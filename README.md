# 🚗 VroomVroom Desktop  

A Tauri + Vue desktop application for controlling an ESP32-based car with a Bluetooth controller.  

---

## ✨ About VroomVroom Desktop  
**VroomVroom Desktop** was developed as part of a school project to facilitate testing and control of a Bluetooth-connected ESP32 car.  

### Features:  
- 🎮 **Bluetooth Control**: Use a Bluetooth controller to operate the car in real-time.  
- 🧪 **Testing Platform**: Served as a testing ground for the car's functionality before transitioning the codebase to a mobile app.  

---

## 🛠️ Tech Stack  
- **Frontend**: Built with **Vue.js**.  
- **Desktop Framework**: Powered by **Tauri**, providing lightweight and efficient desktop app capabilities.  
- **Hardware**: Designed to interface with an **ESP32** for car control.  

---

## 📜 Status  
The application was created as a temporary testing platform and has since been retired. The repository is archived and no longer maintained.
